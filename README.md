# MeetingMate Legal Pages

Ready for GitHub Pages, Netlify, Vercel, or any static host.

## Files

- `/index.html`
- `/privacy/index.html`
- `/terms/index.html`
- `/assets/style.css`

## Before publishing

Replace `support@example.com` in:
- `privacy/index.html`
- `terms/index.html`

with your real support email address.

## GitHub Pages

1. Create a new public GitHub repository, for example `meetingmate-legal`.
2. Upload all files from this folder.
3. Open Repository Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save.
7. GitHub will provide a public URL.

Example:

`https://YOUR_USERNAME.github.io/meetingmate-legal/privacy/`

Use the privacy URL as the App Store Connect Privacy Policy URL.

Terms URL:

`https://YOUR_USERNAME.github.io/meetingmate-legal/terms/`
